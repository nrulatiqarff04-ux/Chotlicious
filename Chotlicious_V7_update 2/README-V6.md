# Chotlicious Website — V6

V6 is an update of the existing Chotlicious V5 GitHub Pages website.

## V6 changes
- Replaced the three Chocojar option images with the newly supplied:
  - Mini Coco Crunch
  - Coco Rice
  - Coco Ball
- Removed the white backgrounds from the supplied product photos and exported them as transparent PNG cutouts.
- Normalised all three product images to the same 800×800 canvas and the same visible product bounding-box size for consistent display.
- Updated both the Shop cards and Chotlicious Line-up to use the new V6 product images.
- Changed the pink accent colour from a very pale pink to a deeper, more readable pink while keeping the brown + green + pink identity.
- All other V5 content and functionality remains unchanged.

## GitHub Pages
Upload/replace the V6 root files in the existing `Chotlicious` repository. Add/replace the V6 images inside the existing `assets` folder. Do not delete the older V4/V5 assets that are still referenced by the website.
