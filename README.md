# Chotlicious Website — V3

This is the V3 visual update of the existing Chotlicious GitHub Pages website.

## What changed in V3

- Replaced the main-page hero cutout with the supplied **Chocojar V2** artwork and placed it larger toward the lower-right of the hero.
- Replaced the base website backdrop with the supplied **-3.jpeg** texture.
- Replaced the **“Made with Love — Our Commitment to Chocolate Joy”** image with the supplied **Chocojar Side** artwork.
- Replaced the product pictures in both the **Shop** cards and the **Chotlicious Line-up** with the supplied latest versions:
  - Coco Ball latest ver
  - Mini Coco Crunch latest ver
  - Coco Rice latest ver
- Kept the existing brown + green + pink colour direction, typography, navigation, cart behaviour, checkout demo, wording and overall section structure.

## GitHub Pages

Upload/replace the contents of this folder in the root of your existing `Chotlicious` repository. `index.html`, `styles.css`, `app.js` and `payment-result.html` should be at the repository root, with the new `assets` folder beside them.

The checkout remains a demo unless connected to a real payment gateway/backend.
