# Chotlicious Website V2

A visual redesign for the Chotlicious Cocojar student e-commerce project.

## Visual direction
- Chocolate brown + matcha green + soft pink
- Watercolour/paper backdrop based on the supplied reference texture
- Editorial dessert-brand layout inspired by the supplied website reference
- Three product flavours: Coco Ball, Mini Coco Crunch, Coco Rice
- RM10 per jar

## GitHub Pages
Upload the contents of this folder to the root of the repository so `index.html` is at the top level. Then publish `main` / root in GitHub Pages.

## Important
Checkout is demo mode. A real payment gateway requires a secure backend and merchant credentials; never put gateway secret keys in `app.js` or other public files.
